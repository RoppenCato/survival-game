# art/: characters built in Blender, rendered to sprites

A trial begun 2026-10-09 (Robin: see whether Blender is the way to make characters and creatures). Until now every picture in
the game was drawn in code; this folder is the first place where a model lives in a file and the game gets a rendered sheet.

- `source/*.blend`: the models with their rigs and animations. **Generated by the build scripts, not hand-edited**: a change goes
  into the script and the .blend is rebuilt, so the model stays reproducible and the file can be opened in Blender to look at.
- `build/toon.py`: the shared look: the toon material (base tone, cool shadow side, small warm light, grain), the sun upper left,
  the orthographic three-quarter camera (35 degrees above the ground), the Freestyle ink line (the whole-silhouette contour heavy
  toward the lower right, a thinner line at real overlaps).
- `build/hero_build.py`: the hero, built from simple shapes on a basic rig with an idle and a walk, and the gear pieces (helmet,
  mail) as separate meshes in the Gear collection. `build/probe.py` prints which way each bone turns.
- `build/render.py`: renders any character's .blend: every animation, direction and layer to `art/render/<name>/` at double size.
- `tools/sprites.js` crops to one box round the foot anchor, halves and packs the sheets into `assets/sprites/<name>/` with a JSON.
- `tools/blender.js` finds blender.exe (or `BLENDER` in the environment) and runs a script headless.

```
npm run art:mixamo     # build hero2 (build/hero2_build.py) and bind it to the Mixamo skeleton: source/hero2_mixamo.blend
npm run art:icons      # each thing alone as an icon for the bag (assets/sprites/items)
npm run art:rocks      # the mountains' set pieces (the cave, mine and sea cave mouths, the rock shelter): modelled, rendered once each and packed into assets/props
npm run art:vasen      # the draugr, the huldra, Nacken and the bysen (art:draugr, art:huldra, art:nacken, art:bysen), then vasen.png
npm run art:trolls     # the four trolls (art:troll:boulder, :forest, :maw, :three), then trolls3d.png
npm run art:beasts     # the boar, the deer and the wolf: modelled, rigged, animated, rendered and packed (art:boar, art:deer, art:wolf for one)
```

**Mixamo (2026-10-09):** the hero's animations come from Mixamo (`source/mixamo/`, its README lists every file and its source
animation). Mixamo's auto-rigger could not rig the hero's own mesh, so `build/hero2_proxy.py` makes a **rigging proxy** (the body
joined and voxel-remeshed into one watertight surface, `source/hero2_rigproxy.fbx`) that Mixamo rigs instead; `build/mixamo_bind.py`
then binds the real parts to that skeleton (each part already named by its bone, the hands on the forearms since the No Fingers
skeleton has no hand bones), collects every clip's action and saves `source/hero2_mixamo.blend`, which `build/render.py` renders
like any other (the armature sits under a 'Turn' empty for the directions). The downloads land in Downloads under temporary
names. `render.py --frames` takes a count per clip (`idle=16,walk=12,8`) and `tools/sprites.js` packs each at its own count;
The old Mixamo hero's sheets (`assets/sprites/hero2-mixamo`) and the scripts that made them were deleted on Robin's word, 2026-10-26 (git keeps them); the hero is Colin, AD's kit, `assets/sprites/hero-kit`, built and rendered in his studio. `source/hero2_mixamo.blend` and the Mixamo clips stay as sources.

**The style test (2026-10-09):** `build/hero2_build.py` is the second hero, about 3.75 heads, chunky, built in a **T-pose** so Mixamo
can auto-rig it (`source/hero2_tpose.fbx` is the joined body mesh); its rig is calibrated at build time (which local axis swings a
bone down, forward or outward is measured, so the animations are written in those words). `toon.py` renders any character in
three styles, `--style cel | painted | folk`, rebuilding every material from its stored colour and pattern (`restyle`).
Robin picked the cel style; the style test's sheets (the first hero, and hero2 in cel, painted, folk and fitted) and its comparison
scripts were removed in the cleanup of 2026-10-15 (`build/hero_build.py` and the .blend files are kept as sources).

Directions go clockwise from facing the camera: s, sw, w, nw, n, ne, e, se. The frame's anchor is the point between the feet.

The **Art Editor**'s Models tab (`npm start`, then Art Editor) shows every packed sheet: pick a model and its gear, walk round the
starter island, the arena or the night forest with it, and see the sheet. Rebuild the pages after new sheets: `npm run build`.
