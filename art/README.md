# art/: characters built in Blender, rendered to sprites

A trial begun 2026-10-09 (Robin: see whether Blender is the way to make characters and creatures). Until now every picture in
the game was drawn in code; this folder is the first place where a model lives in a file and the game gets a rendered sheet.

- `source/*.blend`: the models with their rigs and animations. **Generated by the build scripts, not hand-edited**: a change goes
  into the script and the .blend is rebuilt, so the model stays reproducible and the file can be opened in Blender to look at.
- `build/toon.py`: the shared look: the toon material (base tone, cool shadow side, small warm light, grain), the sun upper left,
  the orthographic three-quarter camera (35 degrees above the ground), the Freestyle ink line (the whole-silhouette contour heavy
  toward the lower right, a thinner line at real overlaps).
- `build/hero_build.py`: the hero, built from simple shapes on a basic rig with an idle and a walk, and the gear pieces (helmet,
  mail) as separate meshes in the Gear collection. `build/probe.py` prints which way each bone turns.
- `build/render.py`: renders any character's .blend: every animation, direction and layer to `art/render/<name>/` at double size.
- `tools/sprites.js` crops to one box round the foot anchor, halves and packs the sheets into `assets/sprites/<name>/` with a JSON.
- `tools/blender.js` finds blender.exe (or `BLENDER` in the environment) and runs a script headless.

```
npm run art:hero       # build the .blend, render every frame, pack the sheets
npm run art:compare    # herocompare.png: the drawn hero beside the rendered one
npm run art:styles     # the style test: hero2 in the three styles over the Night Forest, herostyles.png
```

**The style test (2026-10-09):** `build/hero2_build.py` is the second hero, about 3.75 heads, chunky, built in a **T-pose** so Mixamo
can auto-rig it (`source/hero2_tpose.fbx` is the joined body mesh); its rig is calibrated at build time (which local axis swings a
bone down, forward or outward is measured, so the animations are written in those words). `toon.py` renders any character in
three styles, `--style cel | painted | folk`, rebuilding every material from its stored colour and pattern (`restyle`).
`tools/visual/herostyles.js` puts the three side by side over a Night Forest painted from the game's own props.

Directions go clockwise from facing the camera: s, sw, w, nw, n, ne, e, se. The frame's anchor is the point between the feet.
