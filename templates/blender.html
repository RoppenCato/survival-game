Blender Editor

The characters modelled in Blender and rendered to sprite sheets (art/). Pick a model, stack its gear, and walk round the arena or the night forest with it. The sheets are what the build found in assets/sprites/; make new ones with npm run art:hero or npm run art:styles, then npm run build.

The sheet

A row per direction, a column per frame, at 1x (the game's 3 px a unit).

Controls

WASD
Walk. Hold Shift to sprint
Space
Dash
H
Spawn a beast

Model

Gear

Each piece is its own layer, rendered over the body as a holdout, so they stack in any order.
